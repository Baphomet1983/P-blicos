## Descripción larga para pegar en Payhip
¿Tu inventario no cuadra y necesitas una forma ordenada de investigar antes de ajustar el sistema?

Inventory Intelligence es un laboratorio escrito de autoaprendizaje que te guía por un caso de inventario con datos ficticios. Practicarás cómo comparar conteos, identificar faltantes y sobrantes, estimar su impacto, priorizar con Pareto/ABC y formular consultas SQL iniciales.

**Recibirás un paquete descargable con:**
1. Curso escrito paso a paso, ejercicios y respuestas orientativas.
2. Workbook editable con datos ficticios, fórmulas, resumen ejecutivo y ejemplos SQL.
3. Bono: Manual práctico de APIs — HTTP/JSON, ejemplos de Python y JavaScript, credenciales, errores y seguridad.
4. Bono: Manual práctico de agentes de IA — arquitectura, prompts, herramientas, evaluación, límites y supervisión humana.

**Ideal para:** supervisores de operaciones y bodega, encargados de inventario, analistas logísticos junior y personas que quieren pasar de Excel a SQL aplicado a operaciones.

**Nivel:** introductorio. Conviene conocer las fórmulas básicas de Excel.

**Precio:** US$17, pago único.

**Importante:** los datos del workbook son simulados; los resultados del ejercicio no representan el rendimiento de una empresa real. Este producto no incluye videos, clases en vivo, tutorías, soporte personalizado, certificado acreditado, integración con ERP/WMS ni código de agentes listo para producción. Los ejemplos de API son ilustrativos y deben adaptarse y probarse en un entorno autorizado. No se prometen ahorros ni resultados laborales.
